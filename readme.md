# Java Practice & Management Systems

A collection of **Java-based applications and programming practice projects** developed to strengthen my understanding of Core Java, Object-Oriented Programming, classes, objects, and application-level problem solving.

## 📌 Projects Included

### 🚕 Taxi Management System

A Java-based taxi management application designed to handle taxi-related operations and customer booking details.

**Main Components:**

- Taxi management
- Customer management
- Booking management
- Taxi-related operations

### 🎓 Student Management System

A Java application for managing student-related information.

**Main Components:**

- Student details
- Student management operations
- Data handling using Java classes and objects

### 🏦 Bank Management System

A Java-based banking application that demonstrates basic account and banking operations.

**Main Components:**

- Account management
- Bank management
- Customer/account-related operations

### 🎫 Booking System

A Java application that demonstrates booking-related operations using classes and objects.

**Main Components:**

- Booking management
- Customer management
- Booking-related operations

## 🛠️ Technologies Used
